# Этапы ModifierDemo

Каждый этап ниже собран настоящим `:app:assembleDebug` до коммита. APK и полные логи находятся вне Git: `C:/AndroidProjects/_lab02_evidence/ModifierDemo/`; UI-проверка всех этапов пока ожидается.

## 01. Create ModifierDemo Empty Activity

Коммит: `2f6bd5699a6ea7f9c246c87a0696f73443346d51`; лог: `logs/01.log`; APK: `apks/01.apk`.

Создан самостоятельный Compose-проект Empty Activity с minSdk 27 и собственным репозиторием. Запуск MainActivity должен показать исходное приветствие Hello Android!; первая настоящая сборка подтверждает совместимость выбранных версий.

## 02. Show Hello Compose in DemoScreen

Коммит: `5861b751c5216ab19e0a1d6fdb042c356aa4205b`; лог: `logs/02.log`; APK: `apks/02.apk`.

Greeting заменён на DemoScreen с Hello Compose, размером 40.sp и жирным начертанием, добавлен Preview. Входной modifier сохраняет отступ Scaffold, поэтому текст не должен оказаться под системной панелью; проверить это предстоит на устройстве.

## 03. Create empty Modifier chain

Коммит: `66500a578349fd58c2df17ae77a3d477901229e3`; лог: `logs/03.log`; APK: `apks/03.apk`.

Объявлена явная пустая цепочка Modifier, переданная тексту после входного модификатора. Пустая цепочка не добавляет оформления, поэтому ожидаемый вид не меняется; отдельный коммит фиксирует именно учебное действие.

## 04. Apply padding modifier to greeting

Коммит: `568cf85e8122b980833552dcc0753de913b60fe4`; лог: `logs/04.log`; APK: `apks/04.apk`.

Добавлен padding(all = 10.dp) вокруг приветствия. dp задаёт логический отступ, а не фиксированное число физических пикселей; сравнить расстояния с этапом 03.

## 05. Add border after padding

Коммит: `5b4b5fe08d7e3a9dd166d0cc08ea3831a239590f`; лог: `logs/05.log`; APK: `apks/05.apk`.

После padding добавлена чёрная рамка толщиной 2.dp. Она охватывает текст внутри уже выделенного внешнего отступа; сравнить с последующим обратным порядком.

## 06. Preserve incoming modifier and place border outside padding

Коммит: `1bb29f8fd010c0434fae46389deb05e49aa15e94`; лог: `logs/06.log`; APK: `apks/06.apk`.

Цепочка теперь начинается с входного modifier, затем идёт border и padding. Рамка окружает и текст, и внутренний отступ, а innerPadding не теряется и не применяется повторно; это дизайн рисунка 1.

## 07. Pass greeting modifier positionally

Коммит: `16cc37cc945fa983116401ec7fc9b0cb97491f6b`; лог: `logs/07.log`; APK: `apks/07.apk`.

Модификатор передан вторым позиционным аргументом Text вместо именованного аргумента. Это допустимо по сигнатуре функции, а внешний вид должен остаться прежним.

## 08. Place border inside padding

Коммит: `ef49518ec3f80bfd54abc77151176ce284d73f5c`; лог: `logs/08.log`; APK: `apks/08.apk`.

Порядок снова изменён на padding().border(). Теперь десять dp расположены снаружи рамки, поэтому сравнение этапов 06 и 08 иллюстрирует рисунки 1 и 2.

## 09. Introduce CustomImage composable

Коммит: `30e17bde588b1f2f34af72312a7996c3dde87a1e`; лог: `logs/09.log`; APK: `apks/09.apk`.

Добавлен CustomImage с обязательным идентификатором ресурса image и вызовом Image. Компонент пока не используется на экране, поэтому визуальное отличие не ожидается; наличие функции проверяется исходником этого коммита.

## 10. Add required CustomImage modifier parameter

Коммит: `c766492a6e36335b293a3541ba510e916b8f4e76`; лог: `logs/10.log`; APK: `apks/10.apk`.

У CustomImage появился обязательный параметр modifier. Это намеренно промежуточная сигнатура из лекции: на этом этапе параметр ещё не влияет на Image и вызов обязан его передать.

## 11. Make CustomImage modifier optional

Коммит: `57ff4bd30cba469d17a2e3515b048a79ecd75f58`; лог: `logs/11.log`; APK: `apks/11.apk`.

Параметру modifier задано значение по умолчанию Modifier. Теперь вызывающий код сможет не указывать оформление, но передача параметра к корню ещё предстоит следующим действием.

## 12. Forward CustomImage modifier to Image

Коммит: `abce6f94aba5c85275776463127584f574769a78`; лог: `logs/12.log`; APK: `apks/12.apk`.

Принятый modifier передан корневому Image. Компонент теперь поддерживает оформление вызывающей стороны без собственного дублирования цепочки; отдельный UI-тест в последующем проверяет переданный размер.

## 13. Import original vacation drawable

Коммит: `fa75bc4c8980015d0b1ce57e48bff9aaaf0100c4`; лог: `logs/13.log`; APK: `apks/13.apk`.

Оригинальный vacation.jpg скопирован побайтно в res/drawable без замены и перекодирования. Проверка SHA-256 подтверждает соответствие ресурсу курса; изображение начнёт отображаться на следующем этапе.

## 14. Compose greeting spacer and vacation image

Коммит: `52fa1399c8dc145bf9394abc453a8364f479eb58`; лог: `logs/14.log`; APK: `apks/14.apk`.

Добавлены Column с padding 20.dp, центрированием детей, Text, Spacer высотой 16.dp и CustomImage без явного modifier. В отличие от опечатки в примере, входной modifier применяется один раз к корневому Column, а не только к Text; сравнить с рисунком 5.

## 15. Pad size and round vacation image

Коммит: `eb54ad6da5352a1b6a0f580b93c76fa6e66e066c`; лог: `logs/15.log`; APK: `apks/15.apk`.

Для картинки передана цепочка padding(16.dp).width(270.dp).clip(RoundedCornerShape(30.dp)). Отступ находится снаружи изображения, ширина ограничивается родительскими constraints, углы контента обрезаются; сравнить с рисунком 6.

## 16. Combine text modifiers with then

Коммит: `0f89b29aac999341a394dc662a15056943636e17`; лог: `logs/16.log`; APK: `apks/16.apk`.

Создан отдельный secondModifier = Modifier.height(100.dp) и присоединён к оформлению текста через then(). Порядок border → padding → height сохраняется: высота относится к внутренней области, а внешний отступ добавляется вокруг неё.

## 17. Add accessible image descriptions and Compose UI tests

Коммит: `432e9c8599023051db05d03b19d76539a937e646`; лог: `logs/17.log`; APK: `apks/17.apk`.

Добавлено необязательное описание изображения, которое DemoScreen получает из строкового ресурса; декоративное использование по умолчанию сохраняет null. Подготовлены пять instrumented-тестов на приветствие, доступность, значение modifier по умолчанию, переданный размер и высоту текста; они скомпилированы, но выполнение на устройстве передано родительскому агенту.
